\section{Prompts}
\label{app:prompts}

All prompts, verbatim from the implementation. The reader prompt is shared
by every architecture; the instruction to output only the answer exists
because the gold answers are short spans (Section~\ref{sec:setup-metrics}).

\paragraph{Reader (all architectures).}
\begin{quote}\small\ttfamily\raggedright
Answer the question based on the given documents. Only give me the answer
and do not output any other words.\\[2pt]
Documents:\\
{[}1{]} \ldots\ {[}k{]} \ldots\\[2pt]
Question: \{question\}
\end{quote}

\paragraph{ClosedBook reader.} As above, minus the documents block.

\paragraph{HyDE drafter.}
\begin{quote}\small\ttfamily\raggedright
Write a short encyclopedia passage that answers the question.\\[2pt]
Question: \{question\}\\[2pt]
Name the people, places, dates and titles involved. Write it as an
encyclopedia entry, not as a reply to the question. If you are not sure of
the facts, write the most plausible passage anyway. Reply with only the
passage.
\end{quote}

\paragraph{IRCoT reasoning step.}
\begin{quote}\small\ttfamily\raggedright
You are answering a question step by step using the documents below.\\[2pt]
Documents: \ldots\\
Question: \{question\}\\
Reasoning so far: \ldots\\[2pt]
Write the next single sentence of reasoning. Name the entities that still
need to be looked up. If the documents already answer the question, write
"So the answer is: <answer>".
\end{quote}
The one-shot variant prepends a single hand-written two-hop worked example
(identical for every question set).

\paragraph{CRAG retrieval grader.}
\begin{quote}\small\ttfamily\raggedright
Judge which documents contain information useful for answering the
question.\\[2pt]
Documents: \ldots\\
Question: \{question\}\\[2pt]
Reply with only the numbers of the useful documents, separated by commas.
If none of them are useful, reply with "none".
\end{quote}

\paragraph{CRAG query rewrite.}
\begin{quote}\small\ttfamily\raggedright
The search results for this question were not useful.\\[2pt]
Question: \{question\}\\[2pt]
Write a better search query for finding the documents that answer it.
Spell out the entities the question only refers to indirectly. Reply with
only the query.
\end{quote}

\paragraph{Adaptive-RAG router.}
\begin{quote}\small\ttfamily\raggedright
Classify how much looking up the question needs.\\[2pt]
Question: \{question\}\\[2pt]
A - a widely known fact that needs no source, such as a famous person,
country or date.\\
B - one fact that has to be looked up in a single document.\\
C - several facts from different documents that have to be combined, for
example when the question refers to an entity it does not name.\\[2pt]
Reply with only the letter A, B or C.
\end{quote}

\paragraph{Abstention phrases.} An answer is counted as an abstention if,
after normalisation, it contains any of: \emph{do(es) not contain, no
information, not mentioned, can(not) answer, not provided, no mention,
unable to answer, not enough information, insufficient information, there
is no, not possible to determine} --- or if it is longer than twenty
words.
